# 温度转换程序 · 项目共享上下文

## 项目目标

构建一个命令行温度转换工具，用来演示 Python 项目中的记忆记录与跨 Agent 接续。

## 目录与稳定事实

- 项目根目录：本文件所在目录。复制示例后，接手 Agent 先确认实际绝对路径。
- 运行环境：Python 3.10 或更高版本，无第三方依赖。
- 入口：`temperature.py`；测试：`test_temperature.py`。
- 全局规则：沿用使用者已配置的个人全局入口，本例不包含私人身份与路径。
- 项目共享状态只维护在本文件，各端适配器只放读取要求和该端规则。

## 当前状态

- 已提供摄氏转华氏函数及 CLI，支持负数和小数，结果保留两位小数。
- 非数字输入和非有限数值在 CLI 中报错，退出码为2；正常转换退出码为0。
- 本轮检查记录见下方“验证方式”；接手者在自己的环境中重新运行并记录结果。
- 尚未实现华氏转摄氏；它是下一次交接练习的任务。

## 已确认决策

以下是本示例选定的设计，复制后可由项目所有者调整。

- 只使用 Python 标准库，先保留单文件程序和单文件测试。
- 转换函数与命令行入口分开，导入模块时不执行 CLI。
- 这里只做数学换算，不增加物理温度下限判定。
- 当前命令 `python temperature.py 25` 的行为保持兼容。
- 验证方法和完成状态写在本文件，不在多个 Agent 适配器中重复记录。

## 下一步

增加华氏转摄氏功能。建议新增 `--from-unit F` 参数，默认仍为 C；先增加测试，再实现。
至少验证 `32 F → 0 C`、`212 F → 100 C`、`-40 F → -40 C`，并保留现有摄氏输入行为。

## 验证方式

在本目录执行：

```sh
python -B -m unittest -v
python -B temperature.py 25
python -B temperature.py -- -40
```

通过条件：单元测试全部通过；两条转换命令分别输出 `25.00 C = 77.00 F` 和 `-40.00 C = -40.00 F`，退出码均为0。
解释器名为 `python3` 的环境可替换命令前缀。

维护时验证记录：2026-10-20，Windows / Python 3.14.6，执行上述命令，6项测试通过，两条 CLI 输出与预期一致；Python 3.12.14 下也通过6项测试。3.10和3.11未在本轮实测。这是参考代码的运行记录；复制后的环境、Agent 自动加载与两端交接需分别核验。
